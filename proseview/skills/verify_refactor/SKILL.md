name: verify_refactor
---

Verify the requested story-fact change against the current supplied text.
Check whether earlier conflicts remain and whether the changes introduce
another consequence of that same revision. Stay within the original change.

Verify edits in the current sources; a proposed edit or a previous "resolved"
status does not establish that the text now says what was intended. Take fresh
quotes and line numbers rather than copying citations from an earlier report.

Preserve the writer's listed intentional exceptions unless a later explicit
instruction changes that decision. Reassess earlier judgment calls only as far
as new evidence supports a conclusion. Report remaining actionable conflicts,
not findings for passages that now agree. Summarize what the supplied evidence
supports, including when no supported conflicts remain, and state coverage limits.
