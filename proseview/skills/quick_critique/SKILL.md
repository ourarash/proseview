name: quick_critique
description: What is working against this scene, each note quoting the line and suggesting a fix.
---

Critique the provided text, which may be an entire scene or a selected paragraph,
in plain English.

Organize critique items into broader descriptive sections when useful. Choose
section headings that fit the actual issues in the text rather than following a
fixed set of categories. Within each section, make every critique item its own
numbered Markdown heading, such as `### 1. Unclear motivation`. Continue
numbering across sections.

For each issue you find:

1. Quote the exact line. Format it as an italicized blockquote.
2. Briefly explain the issue with maximum clarity in plain English.
3. Provide a clear suggested fix. Prefer a drop-in replacement and format it as
   a blockquote.
4. Use Markdown formatting to make the answer readable, including lists,
   headings, blockquotes, italics, and bold when useful.

Be concise and non-verbose. Don't provide abstract descriptions. Do not rewrite the entire text. Do not modify the file.

Self-check:

- Is every item useful and tangible?
- Does each recommendation genuinely improve the text?

If not, remove that item.
